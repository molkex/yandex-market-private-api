# yandex-market-private-api — паспорт проекта

> Для агентов Manager. Сгенерировано автоматически 2026-10-19 по коду репозитория, проверь и поправь при необходимости.

**Что это.** Документационный репозиторий коммерческого Python SDK для неофициального доступа к Yandex Market через эмуляцию iOS/Android-приложений: поиск товаров, DivKit SDUI, реферальные/B2B-награды и headless-регистрация по телефону. Для разработчиков и компаний, которым нужен доступ без официального Partner API и без физических устройств или эмуляторов.
**Стек.** Python >=3.9 (SDK; стандартный http.client, опционально brotli и curl_cffi); в репозитории только README/Markdown и PNG; DivKit SDUI, эмуляция iOS/Android, TLS/JA3/JA4.
**Статус.** неясно (по датам коммитов)
**Где работает.** неизвестно; репозиторий — только документация, SDK поставляется отдельной защищённой сборкой по лицензии; локальный web dashboard входит в лицензионную сборку
